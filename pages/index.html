O que é Teste de Software?

O teste de software é o processo de avaliação e verificação de que um sistema ou aplicação faz o que deveria fazer...

Qual a importância de testar?

Redução de custos a longo prazo, segurança do usuário, reputação da marca e facilidade na manutenção do código.

Quando o código falha: Exemplos Históricos

Therac-25 (1985)

Uma máquina de radioterapia que, por um bug de concorrência no software, administrou doses letais de radiação em pacientes.

Ariane 5 (1996)

O foguete europeu explodiu 40 segundos após o lançamento devido a uma conversão incorreta de dados no software.

Tipos de Teste de Software

  • Testes Unitários: Testam a menor parte testável do código isoladamente.
  • Testes de Integração: Verificam se diferentes módulos funcionam bem em conjunto.
  • Testes E2E (End-to-End): Simulam o comportamento do usuário real de ponta a ponta.
  • Testes de Performance: Avaliam o sistema sob alto volume de acessos.
